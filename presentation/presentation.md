# Presentation

This folder contains the presentation markdown. Initially created with Marp, subject to change.

## Compiling

To compile the presentations, you need to have [Marp](https://marp.app/) installed. You can then run the following command:

From the `presentation` folder:
```bash
marp --pdf filename.md # Compile pres.md to pres.pdf
```

Another way to do it is with the VsCode extention Marp
